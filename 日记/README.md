自 2026-11-02 调整分工后，助手主要指导当前选定项目，Python、C++ 等基础由本人自主学习。本人汇报进度或结束本次学习时，结合已有项目记录按实际日期归档：自学注明汇报来源，项目记录真实操作、结果、证据与帮助程度。日期只用于成果归属，不安排今日/明日任务；同日多段可合并并区分收尾，跨日继续同一检查点，不自动换项目。未汇报不推断为未学习，归档或结束本次学习不等于项目完成。历史日记保留当时的学习安排。

跨会话恢复先读[项目计划中的当前项目与断点](../project-learning-plan.md)，再按需查日记证据；不能因最新日记只记录自学而改换项目，也不能用补归档的旧日期覆盖当前断点。

按本人要求，17 日补学内容单独归档到 `2026-10-17.md`，正文注明实际学习于 18 日；18 日日记集中记录当日原定周验收，两段用时分开。

## 新日记格式

```markdown
# YYYY-MM-DD 日记

## 今日成果

### 自主学习进度

- 本人汇报：实际学习的主题、章节或练习，以及已提供的进度和疑问；有材料时添加相对链接。

### 项目推进成果

- 实际推进的项目检查点、结果与证据链接；注明本人操作或助手帮助，以及通过、未通过或待验证的状态。

## 本次收尾与续学位置

- 当前项目与阶段/检查点：
- 本次已完成及证据、帮助程度：
- 未完成操作、卡点、待回答问题（保留必要题干与输入）：
- 下次具体第一步：
- 本次状态：结束本次学习/暂停；项目完成须另有全部验收证据。

## 备注

- 自学疑问与其他待验证事项；不生成下一天任务。
```

按实际记录填写，不要求每天都有新增成果或每段都填满模板；只有自学汇报也可以归档，不移动项目断点。本人明确结束/暂停时，无新增通过项也须保存原位置；仅修改约定且未开课时不制造成果日记。同日多次汇报合并补充，未提供的用时、运行结果或理解程度保持未知。
