# 每日日记

[← 项目总览](../README.md)

按本地日期（Asia/Shanghai）建立 `YYYY-MM-DD.md` 文件，记录当天**实际完成**的成果，并用相对路径链接到对应文件。计划中的工作和待验证的结果不要写成已完成。

## 新日记格式

```markdown
# YYYY-MM-DD 日记

## 今日成果

- 完成了什么：添加指向成果文件的相对链接

## 备注

- 如有未完成或待验证事项，明确标注状态。
```
