# 2026-10-08 数组与哈希周四变式：保留最后一次请求

- 规则：按 `request_id` 只保留最后一次出现的完整记录，结果按保留记录在原输入中的顺序排列。
- 实施输入约定：每条请求是含非空字符串 `request_id` 与整数 `latency_ms` 的字典；这不是路线图原文。
- 工作目录：项目根目录；Python：项目 `.venv` 中的 3.14.4。

| 输入 | 学习者在运行前给出的预期 | 实际 | 状态 |
| --- | --- | --- | --- |
| `A:10, B:20, A:99, C:5, B:30` | `A:99, C:5, B:30` | `A:99, C:5, B:30` | 通过 |
| 空列表 `[]` | `[]` | `[]` | 通过 |
| `A:10, A:99, A:7` | 保留完整的 `A:7` 记录 | `A:7` | 通过 |

学习者在 [requests_last.py](../python-basics/requests_last.py) 中从右往左扫描、用集合记录已见 ID，再反转结果列表。学习者终端与助手复跑的普通样例及两组边界测试均符合运行前预期。

## 复杂度与时长

- 学习者说明样例中倒序循环 5 次、反转列表有 3 项；据此给出时间 O(n) 的结论。一般情况下倒序循环 n 次，反转至多 u 项，按集合操作通常 O(1) 计，总时间 O(n)；此项已通过。
- 学习者进一步说明 `seen` 与 `kept` 各最多 u 项，合计约 2u 项；当全部 ID 不同时 u=n，最多约 2n 项。忽略常数后，一般额外空间 O(u)，最坏 O(n)。`kept.reverse()` 就地反转，不再创建一份结果列表。空间依据检查通过。
- 学习者报告练习约 20 分钟，未单独计时。
