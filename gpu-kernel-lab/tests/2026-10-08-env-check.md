# 2026-10-08 独立环境检查

- 工作目录：项目根目录。
- 学习者在终端运行 `sudo apt install python3.14-venv`；终端截图显示 `python3.14-venv`、`python3-pip-whl`、`python3-setuptools-whl` 均配置完成。助手随后用 `dpkg-query` 核对三个包为 `install ok installed`。
- 学习者运行 `python3 -m venv .venv`，命令无错误输出；随后运行 `./.venv/bin/python -m pip --version`，显示 `pip 25.1.1` 来自项目 `.venv/lib/python3.14/site-packages`。助手复核 `./.venv/bin/python --version` 为 `Python 3.14.4`，同一 `pip` 检查结果一致。
- 学习者解释：指定 `.venv/bin/python` 是为了检查独立环境的 `pip`。这一检查点通过；新终端按 README 运行统计脚本的验收记录见[统计脚本验收记录](2026-10-08-stats-cases.md)。
- `.venv/` 是本机生成目录，已加入项目 `.gitignore`，不作为可交付文件；应按后续 README 说明重建。
- 学习者创建 `gpu-kernel-lab/python-basics/requirements.txt`，只含一行说明，无第三方包名；解释 `argparse`、`json`、`pathlib` 均由 Python 提供。运行 `./.venv/bin/python -m pip install -r gpu-kernel-lab/python-basics/requirements.txt` 后终端直接返回提示符，无安装错误；助手核对文件内容并复跑，退出码为 0。
