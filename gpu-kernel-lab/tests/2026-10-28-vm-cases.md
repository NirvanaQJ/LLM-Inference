## 检查点：建立只读映射（正常路径通过）

- 在非空的六字节固定输入上，从文件偏移 0 建立 PROT_READ / MAP_PRIVATE 映射。
- 先判断返回值不是 MAP_FAILED，再将返回地址转换为 const unsigned char*，读取 bytes[2]。
- 使用 munmap 解除映射并检查返回值，然后关闭文件描述符。
- 独立预期：size=6、third=C、退出状态 0；本次只核对正常路径，不将未执行的错误路径或完整文件对照写为通过。
- 本人实际报告：`size=6`、`third=C`、`exit=0`，符合预期；助手只读确认源码包含上述调用、输入仍为六字节固定文件，未代跑。[原答与源码快照](../results/raw/2026-10-28-mmap-first-learner-observation.json)

## 检查点：逐字节校验映射（正常路径通过）

- 将第三字节输出替换为对完整映射的遍历，按 unsigned char（0～255）累加到 std::uint64_t 校验和，输出映射字节数和校验和。
- 教学约定：字节和按无符号 64 位加法计算（溢出按模 2^64）；相同字节和不保证任意文件字节完全相同，今天对固定不变的同一文件比较两条读取路径，并核对独立预期。
- 固定输入 ABCDEF 的独立预期：6 字节，校验和 65+66+67+68+69+70=405；输出 size=6、mmap_bytes=6、mmap_sum=405、退出状态 0。
- 本人实际报告 `size=6`、`mmap_bytes=6`、`mmap_sum=405`、`exit=0`，与预期一致。[原答与源码快照](../results/raw/2026-10-28-mmap-sum-learner-observation.json)已保存，助手只读核对未代跑。当前仍是至少 3 字节的教学版本，空文件与短文件支持后续单独验证。

## 检查点：普通 read 对照（运行通过，理解经纠正后通过）

- 实施约定：输入为固定、运行期间不修改的普通文件；先完成 mmap 遍历并解除映射，再用同一 fd 的 read 循环计算字节数与相同字节和。mmap 访问不会推进 fd 的读取位置，初次 read 从文件开头开始。
- 复用昨日 read 循环结构，缓冲区设为 4 字节，处理 EINTR、其他错误与 EOF，每次仅累加实际读到的字节。
- 独立预期：read_bytes=6、read_sum=405、match=yes，正常退出状态 0；不是性能测量。
- 本人实际输出两种方法均为 6 字节、字节和 405，match=yes、exit=0，符合预期。[输出、源码快照与理解题](../results/raw/2026-10-28-read-compare-learner-observation.json)已保存，助手只读核对未代跑。
- 理解检查未通过：题目问单次 read 返回 2 时内层 for 的执行次数，本人答“3次，前两次会读取，第三次会退出”，混淆外层 while 与内层 for。独立预期为 count=2、index 取 0 和 1、累加两次；待局部解释后变式复答，不用正确运行输出替代理解验收。
- 变式复答原文：“3 0 1 2 3,执行3次累加”。count=3、累加三次正确；下标列表包含 3 存在歧义，待确认 index=3 时条件 3<3 不成立、不会访问 buffer[3]，尚未将理解检查标为通过。
- 边界复答：“不成立，不会执行”，正确确认 index=3 时不执行累加，理解检查经纠正后通过。初答与复答均保留于上述原始记录。
