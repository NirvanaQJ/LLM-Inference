## 自测 1：三种独立交换

问题：初始 `a=3、b=8`，分别独立调用 `swap_value(a,b)`、`swap_pointer(&a,&b)`、`swap_reference(a,b)`，返回后原变量各是什么值？为什么？

本人答案：原变量分别为 `a3b8`、`a8b3`、`a8b3`；按值交换，交换的是 a 和 b 的副本，所以原变量不会发生改变，而指针和引用都是直接交换的原变量。

今日检查：通过。三种独立调用的数值及原因正确。

## 自测 2：const 的修饰对象

问题：`const int* p`、`int* const p`、`const int* const p` 分别限制什么？各自能否通过 `*p` 修改整数，能否改变 `p` 的指向？

本人答案：`const int* p` 只能读取变量，不能通过 p 改变变量；`int* const p` 表示可以通过 p 改变变量，但是不能改变 p 保存的地址；`const int* const p` 表示只读，不能通过 p 修改变量，也不能修改 p 的指向。

今日检查：通过。三个声明的限制对象区分正确；第一种的指针自身可改指向，已在此前判断题中由本人回答通过。

## 自测 3：指针参数的三种表达式

问题：`swap_pointer` 中的 `x`、`*x`、`&x` 各表示什么？为什么只交换函数内的 `x/y`，不能交换调用者的 `a/b`？

复习用整理答案（助手依据已验证回答归纳，不冒充本人新一轮原话）：`x` 保存原变量的地址，`*x` 访问该地址处的整数，`&x` 是指针参数 x 自己的地址。函数内的 x/y 是独立指针参数，保存传入地址的副本；只交换 x/y 改变的是局部参数保存的地址，没有写入 a/b 的整数。引用的别名关系应看 `int&` 声明，不能把表达式 `&x` 当作引用声明。

首次错答（保留用于提醒）：x 表示原变量的地址，`*x` 表示该地址指向的值，`&x` 表示引用，x 是原变量的别称，和原变量表示同一个数值；只交换函数内的 xy，相当于交换了 ab 的副本，并没有对调用者的 a 和 b 进行操作。

首答检查：未通过。前两种表达式的解释在本例中正确；`&x` 作为表达式是对指针变量 x 自己取地址，不能解释为引用声明，指针参数 x 也不是整数 a 的别名。只交换局部 x/y 交换的是它们保存的两份地址，不是 a/b 的整数副本。

助手局部提示：区分声明 `int& r = a;` 与表达式 `&x`，并回到函数签名 `swap_pointer(int* x, int* y)` 确认 x/y 的类型。随后用下列变式检查，不修改已经通过的程序：

```cpp
int a = 3;
int b = 8;
int* p = &a;
int* q = &b;
p = q;
```

提问：a/b 是否改变，p 保存谁的地址，`&p` 是谁的地址？

本人复答原话：“a和b不会改变，p保存b的地址，&p取得是p的地址”。

纠错判定：三项均正确。本人已在变式中区分指针保存的地址、指针自身地址和原整数不变，结合首答中正确的 `x/*x` 说明，第 3 题理解复查经提示纠正后通过。保留首次错误，不宣称独立无提示掌握；今日复答不计为次日闭卷复测。
