- [C++ 标准工作草案 stmt.dcl](https://eel.is/c++draft/stmt.dcl)：普通自动存储期块变量离开相应作用域时销毁，顺序与构造相反；核对日期 2026-10-19。
- [C++ Core Guidelines R.1](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines#Rr-raii)：将获取与释放资源配对到对象构造与析构；核对日期 2026-10-19。

- [Linux open(2)](https://man7.org/linux/man-pages/man2/open.2.html)、[close(2)](https://man7.org/linux/man-pages/man2/close.2.html)：只读打开、成功的非负描述符、失败的 -1 与释放句柄；核对日期 2026-10-19。
- [C++ 标准工作草案 except.ctor](https://eel.is/c++draft/except.ctor)、[except.handle](https://eel.is/c++draft/except.handle)：异常转移到处理代码时销毁已构造的自动存储期对象；核对日期 2026-10-19。
- [Linux F_GETFD](https://man7.org/linux/man-pages/man2/F_GETFD.2const.html)、[errno](https://man7.org/linux/man-pages/man3/errno.3.html)：查询描述符标志，失败返回 -1 并记录错误；EBADF 表示无效描述符；核对日期 2026-10-19。
