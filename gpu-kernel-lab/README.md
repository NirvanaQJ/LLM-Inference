# GPU 算子实验

[← 项目总览](../README.md)

这个目录用于学习如何编写、检查和测量 GPU 算子。**算子**是完成一种计算的小程序，例如把两个数组逐项相加。按[项目连续学习计划](../project-learning-plan.md)推进 CUDA、Triton 实验，比较正确性与运行时间，并分析差异的原因。当前选定的是 LLM 推理性能实验，本项目保留 K0 / `K0-ENV-01` 待开始状态；仅本人明确切换时才恢复，不按日期或两线均衡自动插入。Python、C++ 基础课下自学，实验所需知识就地补充讲解。

目前已经有 Python、C++ 基础练习及其测试记录；**尚无已验证的 CUDA 或 Triton 性能结果**。目录骨架不代表相应算子已经完成。

## 文件放在哪里

| 路径 | 用途 |
| --- | --- |
| `python-basics/` | Python 入门程序和运行说明，包括请求去重、日志解析与统计。已有练习的运行方法见[Python 日志统计说明](python-basics/README.md)。 |
| `cpp-basics/` | C++ 基础程序，为后续阅读和编写 CUDA 代码做准备。 |
| `cuda/` | CUDA 算子的实现。后续计划从数组相加、归约等小任务开始。 |
| `triton/` | 使用 Triton 编写的 GPU 算子实现。 |
| `tests/` | 正确性、边界输入和预期值与实际值的对照记录。先确认算对，再比较速度。 |
| `bench/` | 可重复运行的性能测试脚本和计时方法。 |
| `results/raw/` | 原始输入或测量数据，保留每次运行记录。 |
| `results/figures/` | 根据原始数据制作的图表。 |
| `profiles/` | 性能分析记录及其结论，说明观察结果如何对应到代码。 |

## 如何推进

每做一个算子，先写清楚输入、期望输出和边界情况；运行正确性测试后，再固定硬件、软件版本和测试条件进行计时。保留原始结果，记录没有提升或出现错误的情况。详细阶段安排见[总路线图](../LLM-Inference-GPU-Systems-Roadmap-2026-2028.html)，实际完成的内容见[学习日记](../日记/README.md)。
