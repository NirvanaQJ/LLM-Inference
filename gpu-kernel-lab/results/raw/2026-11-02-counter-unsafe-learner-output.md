## 当前源码快照

```cpp
#include <iostream>
#include <thread>
long long counter = 0;
const int increments = 100000;
void worker() {
    for (int i = 0; i < increments; ++i) {
        ++counter;// 由你补一行：把共享的 counter 加 1
    }
}

int main() {
    std::thread t1(worker);
    std::thread t2(worker);

    t1.join();
    t2.join();

    std::cout << "actual=" << counter << '\n';
}
```

源码结构与课堂要求一致，本人补入 `++counter`。共享普通整数的无同步并发修改构成数据竞争，属于 C++ 未定义行为；不保证下次仍为 161588，也不能规定结果只会少算。纸面覆盖模型用于帮助理解，不作为该未定义行为的完整输出模型。
